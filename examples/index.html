Accessibility statement

Built to support keyboard, zoom, and assistive technology use

This example page is designed to align with WCAG 2.1 AA patterns commonly used to support European Accessibility Act readiness for digital services.

  • Semantic landmarks, headings, lists, and form labels are used throughout the page.
  • Interactive elements include visible keyboard focus states and do not rely on color alone.
  • Motion is reduced automatically when the user prefers reduced motion.
  • Status and validation messages for the contact form are exposed through an `aria-live` region.

A production implementation should still be tested with real assistive technologies, automated audits, and legal review against the exact scope of your service.
